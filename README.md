
# IPL Performance Analysis 🏏

## Overview
Analysis of IPL cricket data from 2008 to 2023 using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- JupyterLab

## Key Findings
- Mumbai Indians lead all-time wins with 140+ victories
- Virat Kohli is the top run scorer of all time
- Teams choose to field first more often after winning toss
